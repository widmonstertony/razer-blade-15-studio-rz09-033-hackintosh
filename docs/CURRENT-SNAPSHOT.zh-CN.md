# 当前可用快照与 MIC22X 音频 — 2026-10-09

[English](CURRENT-SNAPSHOT.md)

本快照来自新一轮只读实体 ESP 镜像，保留可用的 V61-P5/R4/HID V12，并加入镜像中的配对 MIC22X 音频二进制。完整镜像只留本机私有。已逐文件核对公开 EFI 白名单，只有 AppleALC 二进制变化。未启用的历史 ACPI、`.before-*`、`FSCK*`、Windows/Ubuntu 启动状态和私人身份均不公开。此次发布没有写实体 EFI 或修改已安装系统。

这轮没有强制睡眠、重启或应用录音。热重启、摄像头、接口、外屏、媒体键、防误触、Watch 解锁和 Windows/Ubuntu 启动尚未重新验收。唤醒约 8–11 秒绿色仍然存在。短时 CPU 样本与没有报告降频，不能证明风扇安静或温度低。

## 复现音频配置

先按[安装说明](INSTALL.zh-CN.md)和[根补丁说明](ROOT-PATCHES.zh-CN.md)操作；限定 26.2 / 25C56，先测试 U 盘 EFI，别覆盖可用的内置 ESP。

1. 使用仓库中的**配对 MIC22X AppleALC**，不是随意拿一个官方 AppleALC 再设 layout 22。Mach-O SHA-256 为 `6f566fa8b58948520adb58472a3bee89a65f4f497a891922a346e6ddf2a0f3b1`。
2. 保留已启用的 AppleALC 和 VerbStub 条目，以及 HDEF `DeviceProperties > Add > PciRoot(0x0)/Pci(0x1f,0x3) > layout-id` 数据 `16000000`，即十进制 22。别混用历史 MIC47/B/X 实验，也不要添加冲突的 `alcid` 参数。
3. 依根补丁指南，使用已审查的**精确 build Modern Audio / AppleHDA 根补丁**。EFI 不能替代系统缺少的 Apple 音频驱动；本仓库不分发 AppleHDA。
4. 保留当前可启动安全策略：`-v keepsyms=1 debug=0x100 amfi=0x80 -lilubetaall`。不能单独删除 `amfi=0x80` 或启用 AMFIPass；之前 TCC1 与当前根补丁组合已经无法启动。这是降低安全性的兼容妥协，不是安全推荐。
5. 保存工作，完整关机，等完全断电后，再通过 U 盘测试 EFI 开机。此前热重启曾让输出无声，完整冷启动恢复输入输出；本快照**不宣称所有热重启已经修复**。
6. 声音设置里选内置扬声器输出、Built-in Microphone 输入。检查静音与音量，实际播放短声音，对麦克风说话观察电平。耳机单独测试；仅显示设备不等于声音可用。
7. 应用里触发录音，并在“隐私与安全性”批准该应用的麦克风请求。硬件音频和应用授权是两回事。机主曾需要经过同意的非标准、单应用范围权限处理；此版本不会分发自动授权脚本或 TCC 数据库。应用始终不弹授权时，应诊断具体应用 / 提示策略，不要为此改 EFI，也不要复制别人的权限数据库。
8. 另测热重启、睡眠唤醒和密码锁屏，全部通过才能视为 U 盘候选验收完成；保留自己的上一份可用音频配置用于回滚。

MIC22X 保留 layout 22 的独立麦克风 / 线路输入组，采用 layout 47 的扬声器 / 耳机链路：`[9,34,18]`、`[8,35,24]`、`[20,12,2]`、`[33,13,3]`，用 PathMapID 212 连接。见[配对资源与复现说明](../Sources/AppleALC-MIC22X/README.md)。

## 键盘灯是独立项目

2026-10-09，机主现有 `osx-razer-led` 工具读到亮度 **0**。执行 `brightness 160` 和 `wave left` 后复查为 160/255，虽然附带 `Unable to create plugin (0xe00002be)` 警告。读数不等于实际灯光已由照片或机主确认。

如果你已有同一个工具，从自己的实际路径传入上述参数即可；本仓库没有安装或分发此工具。不要为了灯光修改 `fnkey`。此版本没有安装登录 / 唤醒自动灯效服务。

## 备份边界

保留完整私有 ESP 备份，**另做可恢复的 System/Data 备份**。GitHub 是脱敏复现目录，不是逐字节私有恢复镜像。SMBIOS 和省略的 Apple 派生文件由每位使用者自行合法提供。R4 用户服务、根补丁、BetterDisplay 设置和应用权限都在 EFI 外，须分别配置。
